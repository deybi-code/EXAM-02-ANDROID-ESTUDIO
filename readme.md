# NewsApp

Aplicación móvil para la Práctica Calificada 02 - Grupo A. Desarrollada en Android Studio con Kotlin.

## Pantallas

* **LoginActivity:** Inicio de sesión de usuario.
* **NoticiasActivity:** Visualización de noticias principales.
* **PerfilActivity:** Información del usuario.
* **ContactosActivity:** Lista de contactos con `RecyclerView`.
* **PrivacidadActivity:** Términos y políticas de privacidad.

## Tecnologías

* **Lenguaje:** Kotlin
* **IDE:** Android Studio
* **Componentes:** XML, Layouts dinámicos, RecyclerView

## Estructura del Proyecto

```text
com.tecsup.newsapp/
├── BaseActivity.kt
├── LoginActivity.kt
├── NoticiasActivity.kt
├── PerfilActivity.kt
├── ContactosActivity.kt
├── PrivacidadActivity.kt
├── Contacto.kt
└── ContactoAdapter.kt
```

## Cómo ejecutar

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/deybi-code/EXAM-02-ANDROID-ESTUDIO.git
   ```
2. Abrir el proyecto en **Android Studio**.
3. Sincronizar Gradle y ejecutar en un emulador o dispositivo físico.
